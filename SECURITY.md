# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/chr1st1ank/context-switch/security/advisories/new).
Include a description of the issue, steps to reproduce, and the affected
component (`cosw`, the Android app, or `contextswitch-core`).

You can expect an acknowledgement within a week. Once a fix is available, it
ships in a new release and the advisory is published.
