# context-switch Android

The Android client for context-switch time tracking.

## Architecture

The Android app integrates with the storage provider interface to read and write time tracking data. It provides:

- Timer lifecycle: start, stop, switch
- Project and tag management
- Report generation
- Background synchronization
- Offline queueing of timer actions

## Development

This component is a native Android application. See the main `docs/architecture.md` for the system design.
